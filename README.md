# Yu-Hsiang Lan — Personal Portfolio

A responsive personal portfolio website designed to introduce my background, front-end skills, and selected projects. It also serves as an online résumé for my front-end developer assistant job applications.

## Features

- Responsive layout for desktop and mobile
- Smooth navigation between sections
- Scroll-based reveal animations
- Project cards with screenshots and links
- Direct contact links

## Built With

- HTML
- CSS
- JavaScript

## Sections

- **About Me** — My background, education, and relevant coursework
- **Skills** — Front-end technologies and tools I have learned
- **Projects** — Four independently completed projects
- **Contact** — Email and GitHub links

## Run Locally

Clone this repository and open `index.html` in a browser. For a local development server, you can use the Live Server extension in Visual Studio Code.
